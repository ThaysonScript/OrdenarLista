# OrdenarLista

Crie um programa para ordenar uma lista de funcionários baseados nos salários que eles recebem. 

Sendo do maior para o menor.
O programa deve ter:

- Uma struct Funcionário (Nome, salario).
- Função de CRUD para a struct. (Criar, Ler, Atualizar e Deletar). 
- O Usuário deve ser capaz de cadastrar quantos usuários quiser. (Use alocação dinâmica, não faça com vetor estático!!!).
- Uma função de ordenar os funcionários baseado no salário USANDO UM Insertion Sort.
- Uma função de ordenar os funcionários baseado na salário USANDO UM Selection Sort.
- O programa deve exibir o tempo de execução de cada uma das funções de ordenação.
- Crie um MENU para que o usuário manipule as entradas.
- As funções referentes ao CRUD, o insertion sort e o selection sort devem estar em seus respectivos arquivos.

Obs: Favor tomar cuidado com a formatação, nomes de variáveis e de funções. Vamos no atentar a boas práticas.


Entrega: Se possível, entregar um arquivo único "SeuNome.zip" com todos os arquivos dentro. 

O arquivo principal deve se chamar main.c (Esse formato de entrega visa otimizar o tempo de correção, permitindo que vocês tenham acesso a nota mais rápido). 

Essa formatação de entrega não vale ponto, é apenas uma sugestão.  

DICA: Parte das funcionalidades já foram implementadas no passado, considere reutilizar  partes que funcionem, fazendo as alterações necessárias, para otimizar o tempo.
